input

Se utiliza para crear un campo de entrada de texto en un formulario.

link

Se utiliza para enlazar un archivo CSS externo al documento HTML.

meta

Se utiliza para definir metadatos sobre el documento HTML, como la codificación de caracteres y la descripción.

col

Define las propiedades de las columnas dentro de un elemento colgroup en una tabla.

embed

Se utiliza para incrustar un archivo del proyecto, por ejemplo un PDF o una imagen SVG.

param

Se utilizaba para definir parámetros en elementos <object>. Actualmente está obsoleta (deprecated) en HTML5 y los navegadores modernos la ignoran, por lo que no produce ningún efecto visible en la página.

source

Se utiliza para especificar múltiples fuentes de audio o video dentro de los elementos <audio> o <video>.
